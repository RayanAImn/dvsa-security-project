# Project Instructions for Codex

When I ask for a PDF, use the `latex-pdf` skill.

For PDF generation:

- Prefer LaTeX when the document needs equations, professional formatting, academic style, or tables.
- Create a `main.tex` file.
- Compile it into `main.pdf`.
- Fix LaTeX errors until the PDF builds successfully.
- Do not only write LaTeX code; actually generate the PDF file.
